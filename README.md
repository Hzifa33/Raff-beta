# رَفّ 4.0.0 — RAFF Library Management System

نظام سطح مكتب احترافي فائق السرعة لإدارة وفهرسة المكتبات وإعارة الكتب والمجلدات، مبني بالكامل بمعمارية **Rust + Tauri 2 + React 18 + TypeScript + SQLite + Zustand** مع الحفاظ الكامل على الهوية اللونية التراثية الأصيلة لـ **رَفّ** (الرقّ الدافئ، خشب الجوز العميق، والذهبي النحاسي).

---

## أبرز المزايا المعمارية والجمالية في الإصدار 4.0.0

1. **معمارية الجيل الجديد (Rust + Tauri 2 + SQLite WAL + FTS5)**:
   - استبدال محرك التخزين النصي بمحرك قواعد بيانات علائقي **SQLite** بوضع `WAL` مع فهارس بحث نصي فوري **FTS5** لدعم عشرات الآلاف من الكتب والإعارات في أجزاء من الملّي ثانية.
2. **الهوية البصرية الأصيلة بتصميم حديث (Modern Bento & Floating Dock + Traditional RAFF Brand Palette)**:
   - الحفاظ على ألوان رَفّ التراثية الأصيلة:
     - **الوضع النهاري (Warm Parchment & Rich Walnut)**: خلفية الرقّ الدافئ (`#f4f1eb` / `#faf8f4`)، نصوص الجوز الغني (`#2b211b`)، ولمسات الذهبي النحاسي (`#b68a3a` / `#c99a45` / `#76501b`).
     - **الوضع الليلي (Deep Walnut & Luminous Brass Gold)**: أسطح الجوز الداكن (`#14110f` / `#1b1714`) مع الذهبي المضيء (`#d0aa60` / `#e3c17a`).
     - **دلالات لونية أصيلة**: الأخضر العشبي للمتاح (`#356f52`)، الكهرماني للإعارة الجزئية (`#835700`)، العقيقي للمستعار/المتأخر (`#ad3f39`)، والأزرق الأردوازي لوضع البحث العام (`#356b98`).
3. **ترقية آمنة وتلقائية من الإصدار 3.0.0**:
   - استيراد تلقائي لملفات `raff-library.json` مع إنشاء نسخة احتياطية فورية قبل الترحيل وعدم المساس بالملف الأصلي.
4. **الحفاظ الكامل على جميع الوظائف وتطويرها**:
   - إدارة الكتب والمجلدات والنسخ والأرقام المرجعية المعيارية (`raf-0001`).
   - الإعارة الكاملة والجزئية للمجلدات والإرجاع التدريجي لكل مجلد على حدة.
   - توليد ومسح الباركود (`Code 128B`) وطباعة ملصقات الرفوف بتحجيم تلقائي ذكي.
   - تحليلات وتقارير متعددة الأبعاد عبر 8 أبعاد مع التصدير إلى `JSON` و`CSV` و`TXT` و`PDF`.
   - حماية وضع الإدارة (`PBKDF2-HMAC-SHA256` بـ 210,000 دورة) ووضع البحث العام الآمن (Kiosk Mode).
